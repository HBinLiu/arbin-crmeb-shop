# route 目录结构说明

## 目录结构

```
:.
├── route.php              # 主路由配置
└── README.md              # 目录说明文件
```

## 文件说明

- **route.php** - 项目主路由配置文件

## 功能说明

route目录用于定义项目的路由规则：

- **路由匹配** - 定义URL与控制器的映射关系
- **路由未匹配** - 处理404情况，返回默认页面
- **应用分发** - 根据域名或路径判断请求的应用（admin、app、kefu等）
- **视图分发** - 根据请求信息智能匹配视图资源文件
- **多端适配** - 实现PC端和移动端自动切换

## 路由规则说明

- 解析请求路径获取应用名称
- 根据应用名称返回不同的视图或API
- 支持域名绑定和路由分组
- 统一处理所有路由匹配情况

## 注意事项

- 修改路由后清除缓存
- 路由规则有优先级，从上到下匹配
- 避免路由冲突
