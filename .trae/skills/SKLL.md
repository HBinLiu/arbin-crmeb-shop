## 技能文档规范

### 1. 文件结构

```
.trae/skills/
├── 技能名称/
│   └── SKILL.md       # 技能说明文档
└── SKLLmd             # 技能列表文档
```

### 2. SKILL.md 格式规范

#### 2.1 文档头部

```yaml
---
name: 技能名称
description: 技能描述
---
```

#### 2.2 文档结构

1. **标题**：技能名称
2. **自动触发说明**：
   - 触发条件（操作触发、内容触发、命令触发）
   - 适用场景（核心场景、辅助场景）
   - 触发机制（调用时机、频率、优先级）
   - 触发后行为（自动分析、展示、建议）
3. **核心内容**：技能相关的技术文档
4. **最佳实践**：开发、使用建议
5. **常见问题**：常见问题及解决方案
6. **参考资源**：相关文档、工具等

### 3. 技能触发机制

#### 3.1 触发方式

- **操作触发**：文件/目录操作时触发
- **内容触发**：文件内容包含关键词时触发
- **命令触发**：执行特定命令时触发

#### 3.2 触发优先级

- **最高优先级**：系统核心技能
- **高优先级**：代码结构技能
- **中等优先级**：开发技能（前端、后端、移动端）
- **低优先级**：辅助工具技能

### 4. 技能开发流程

1. **需求分析**：确定技能的功能和范围
2. **文档编写**：按照规范编写SKILL.md文档
3. **目录创建**：创建技能目录结构
4. **测试验证**：测试技能触发和功能
5. **发布使用**：部署技能供开发人员使用

## 技能使用指南

### 1. 开发人员使用

1. **浏览触发**：浏览相关目录时自动触发对应技能
2. **编辑触发**：编辑相关文件时自动触发对应技能
3. **命令触发**：执行相关命令时自动触发对应技能
4. **手动调用**：通过IDE插件手动调用对应技能

### 2. 技能维护

1. **定期更新**：根据项目变化更新技能文档
2. **技能扩展**：根据新功能添加新技能
3. **技能优化**：优化技能触发机制和内容

## 总结

技能系统是CRMEB项目开发的重要辅助工具，通过规范的技能文档和触发机制，可以帮助开发人员更快地了解项目结构、开发规范和最佳实践，提高开发效率和代码质量。

建议定期维护和更新技能文档，确保其与项目发展保持同步，为开发人员提供持续的支持和指导。
